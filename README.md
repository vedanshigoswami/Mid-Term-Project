# Vedanshi Goswami: Portfolio (HTML + CSS only)

## Publish on GitHub Pages (desktop browser)
1. Sign in at github.com, click **+ > New repository**.
2. Name it exactly `vedanshigoswami.github.io`, set it to **Public**, click **Create repository**.
3. Click **uploading an existing file**. Drag in `index.html`, `style.css` and the whole `assets` folder (keep the folder structure), then click **Commit changes**.
4. Go to **Settings > Pages**. Under Source choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Wait 1-3 minutes. Your live URL will be https://vedanshigoswami.github.io/
6. Repository link: https://github.com/vedanshigoswami/vedanshigoswami.github.io
7. Open the live link, test every button, then paste both links into the PDF's table and re-save it as `26121405_WD_MTProject.pdf`.
